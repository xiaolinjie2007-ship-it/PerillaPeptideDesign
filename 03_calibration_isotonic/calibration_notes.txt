Calibration: Isotonic Regression
==================================================

[Method]
Isotonic Regression (non-parametric, monotonic piecewise mapping)
1 LightGBM + 1 isotonic calibrator = 1 file

[LightGBM Parameters]
Source: Optuna 300-trial search optimal parameters
  max_depth: 8, num_leaves: 62, learning_rate: 0.0635
  subsample: 0.8529, colsample_bytree: 0.6746, bagging_freq: 10
  reg_lambda: 0.8928, lambda_l1: 0.0010, min_child_samples: 16
  min_gain_to_split: 0.0355, max_bin: 110, max_delta_step: 3.7896
  min_sum_hessian_in_leaf: 0.1193, boost_from_average: True, extra_trees: False

[Data Split]
Total: 7,774 (train + val combined)
  Training (80%): 6,219 -> retrain LightGBM
  Calibration (20%): 1,555 -> fit isotonic regression
  Test set (864): untouched

[Calibration Method]
1. Retrain LightGBM on 80% data (Optuna optimal params)
2. Predict on 20% holdout to get raw probabilities
3. Fit Isotonic Regression on (raw_prob, true_label)
4. Prediction: sequence -> LightGBM -> isotonic -> calibrated prob

[Calibration Effect (Test Set)]
Before: min=0.0000  max=1.0000  mean=0.5539
After:  min=0.0000  max=1.0000  mean=0.5285
